# Interactive Python Fundamentals Quiz System

A terminal-based interactive study and self-assessment tool built in Python. Designed to help introductory programming students practice core syntax, control flow, and data structures.

## Features
- **Interactive Terminal Interface:** Menu-driven loop with input validation to prevent crashes.
- **Dynamic Scoring & Feedback:** Evaluates string responses, computes weighted percentage scores, and provides tailored feedback.
- **Error Tracking & Review:** Logs missed questions and displays correct solutions at the end of each attempt.
- **Session History:** Tracks previous attempt scores and highlights the personal best score.

## Concepts Covered
- **Control Flow:** `while` game loops, conditional branching (`if/elif/else`), loop termination (`break`).
- **Data Structures:** Dictionaries (key-value question banks), lists for history and tracking.
- **String Handling:** Text normalization with `.strip()` and `.lower()`.
- **Defensive Programming:** Error handling via `try/except ValueError` for non-integer inputs.
